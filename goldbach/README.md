# Goldbach

Το πρόγραμμα επιτρέπει τον έλεγχο αν ένας αριθμός είναι πρώτος (p), καθώς και την ανάλυση ενός άρτιου αριθμού σύμφωνα με την εικασία του Goldbach (g). Στη δεύτερη περίπτωση, βρίσκει δύο πρώτους αριθμούς (p) και (q), με (p \leq q), επιλέγοντας τον μικρότερο δυνατό (p). Υποστηρίζει αριθμούς από 0 έως (10^{10}) και ελέγχει την εγκυρότητα των δεδομένων εισόδου.
